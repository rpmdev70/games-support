# D A Games Support Site

Static support and privacy pages for mobile games currently published under the
D A Games identity.

The site is designed for deployment through GitHub Pages.

## Structure

- `index.html` — main games landing page
- `styles.css` — shared site styling
- `danger-fish/index.html` — Danger Fish support page
- `danger-fish/privacy.html` — Danger Fish privacy policy
- `images/` — game icons and site images

## Local preview

Open `index.html` using the VS Code Live Server extension.

## Deployment

The production site will be hosted through GitHub Pages.

Future releases may migrate to RPM Digital Labs without requiring changes to the
underlying site structure.
